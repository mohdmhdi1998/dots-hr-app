# DOTS HR — تطبيق الجوال

تطبيق واحد للموظفين والمدراء (أندرويد وآيفون) مربوط بنظام DOTS HR Pro.
بعد الدخول يعرض التطبيق ما يناسب صلاحية المستخدم: المدير يرى تبويب «فريقي» والاعتمادات وتقييم فريقه.

## ما في التطبيق

- **للجميع:** الحضور والانصراف بالموقع، الإجازات والأرصدة، كشوف الرواتب، السلف، الخطابات الرسمية،
  توقيع اللائحة وقواعد السلوك والعقد وتعهد التدريب، التقييم الذاتي والاطلاع على النتيجة، تقييمات 360،
  التدريب والشهادات، الإعلانات، الإشعارات، دليل الموظفين.
- **للمدراء والموارد البشرية:** حضور الفريق اليوم، الطلبات بانتظار الاعتماد (اعتماد/رفض)، تقييم أداء الفريق.

## التشغيل

```
flutter pub get
flutter run
```

عند أول دخول يكتب المستخدم عنوان خادم الشركة، مثل `hr.company.com` أو `192.168.1.10/dots-hr-pro/public`.

## البناء للنشر

- أندرويد: `flutter build apk --release` أو `flutter build appbundle` لمتجر Google Play.
  قبل النشر جهّز مفتاح توقيع خاصًا بالشركة بدل مفتاح التطوير.
- آيفون: يُبنى على جهاز Mac عليه Xcode: `flutter build ipa`، ثم يُرفع إلى App Store Connect بحساب Apple Developer.

للنشر في المتاجر يجب أن يعمل الخادم على `https`.
